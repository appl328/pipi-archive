# PIPI ARCHIVE

피피의 사진·문자·날짜를 저장하는 정적 웹앱. 설치나 빌드 없이 GitHub Pages에서 실행합니다.

## GitHub Pages 배포

1. 이 폴더 안의 `index.html`, `app.js`, `style.css`, `assets/`, `.nojekyll`을 저장소 루트에 업로드합니다.
2. GitHub 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
3. 업로드한 브랜치의 `/ (root)`를 지정하고 저장합니다.
4. 발급된 HTTPS 주소를 열면 됩니다. 하위 경로 저장소도 상대 경로로 동작합니다.

## 사용

- 기록 넣기: 사진, 문자, 날짜 입력 후 저장. PNG/JPG/WebP/GIF, 장당 20MB 이하.
- 최신 기록 날짜순, 한 페이지 4개. 사진을 누르면 크게 열립니다.
- 상세 화면에서 날짜 변경, 문자 수정, 삭제. 삭제 직후 알림의 되돌리기로 마지막 삭제를 복원합니다.
- 사진 좌우 스와이프 또는 화살표 버튼으로 이동합니다.
- 제목의 월은 기기의 현재 월입니다. 월별 필터가 아니므로 지난 기록도 계속 표시됩니다.

## 저장과 백업

- 사진 원본과 문자·날짜는 해당 브라우저의 IndexedDB에 저장됩니다. 새로고침과 브라우저 재시작 후에도 유지되며 삭제도 저장됩니다.
- **GitHub 서버에 사진이 저장되거나 다른 기기와 자동 동기화되지 않습니다.** 같은 주소라도 다른 브라우저·기기는 별도 보관함입니다.
- 브라우저 사이트 데이터 삭제, 시크릿 모드 종료, 기기 분실, 저장 공간 정리로 데이터가 사라질 수 있습니다. 백업 파일을 주기적으로 별도 보관하세요.
- 백업 내보내기: 모든 사진을 포함한 JSON 파일 다운로드.
- 백업 가져오기: JSON 검증 후 기존 기록에 병합. 같은 ID는 현재 기록을 유지합니다. 가져오기는 한 트랜잭션으로 저장되어 실패 시 일부만 저장되지 않습니다.
- 삭제한 기록이 들어 있는 과거 백업을 가져오면 그 기록은 복원됩니다.
- 가져오기 최대 300MB. 사진은 재압축하지 않습니다. 많은 사진은 저장 공간과 메모리를 사용합니다.
- 로컬 미리보기에서 GitHub Pages로 이동하면 주소가 달라 저장소도 달라집니다. 먼저 내보낸 뒤 배포 주소에서 가져오세요.
- 백업에는 사진과 문자가 포함됩니다. **백업 JSON을 공개 GitHub 저장소에 업로드하지 마세요.**

## 로컬 실행

`python3 -m http.server 8766 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8766` 접속. 파일 더블클릭 대신 HTTP 서버 또는 GitHub Pages 사용 권장.

## 자산

사용자 제공 Griun Popcorn 폰트와 아이콘을 사용합니다. 폰트·아이콘에 임의의 오픈소스 라이선스를 부여하지 않습니다. 공개 재배포 권한은 해당 자산의 원래 라이선스를 따릅니다.

애플 홈 화면 아이콘은 사용자 제공 초록 배경 원본을 180×180 PNG로 리사이즈한 `assets/apple-touch-icon.png`입니다. 투명 파비콘과 별도로 연결됩니다.
